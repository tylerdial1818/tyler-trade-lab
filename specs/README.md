# Pre-registrations

Each file states a hypothesis, the data, the scoring rule, the decision rule and the failure criteria for one experiment.

A spec is **registered** when its `status` is changed from `draft` to `registered` in a commit made before any test-period data is examined. That commit's hash and timestamp are the record. After registration, changes go in a new section at the bottom with a date and a reason. Nothing above it is edited.
